# Onsaldo — demo księgowe

Responsive, static HTML prototype with two screens:
- `index.html` — Obszary księgowe (entry page)
- `obszary-ksiegowe.html` — Obszary księgowe
- `rejestry-vat.html` — Rejestry i VAT

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Deploy to Vercel
Import this repository in Vercel as a **static site**. Leave the framework preset as **Other** and the build command empty. The output directory is the project root (`.`).

All data is demo-only and no backend/API is connected.
